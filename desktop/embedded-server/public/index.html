iOS 클립보드 연동 가이드

1. Mac 경유 유니버설 클립보드 (자동 연동)
Mac에서 ClipSync가 실행 중이면 Windows에서 복사한 텍스트·이미지가 Mac 시스템 클립보드로 자동 반영됩니다. 동일한 Apple ID(Handoff 활성화)의 iPhone에서는 별도 앱 실행 없이 붙여넣기만 누르면 즉시 입력됩니다.
2. iOS 단축어(Shortcuts) 연동
iOS 단축어 앱에서 아래 URL을 가져와 클립보드에 복사 동작을 연결하면 뒷면 탭 또는 동작 버튼으로 언제든 최신 클립보드를 불러올 수 있습니다.

동기화 키 및 기기 설정

데스크탑(Windows / macOS) 앱에 설정된 Sync Key(동기화 방 키)와 동일한 키를 입력하면 해당 기기 간에만 격리되어 동기화됩니다.
